# Gestion Parfumerie — Logiciel de Caisse & Stock 🌸

Application web de gestion commerciale développée en **PHP** et **MySQL** pour les magasins de parfumerie et cosmétiques en Algérie.

---

## 📋 Fonctionnalités

- 📦 **Catalogue & Gestion du Stock :** Gestion des parfums, contenances, seuils d'alerte, prix d'achat et prix de vente.
- 🧾 **Point de Vente (POS) :** Enregistrement rapide des nouvelles ventes avec calcul automatique du total.
- 💰 **Suivi des Dépenses :** Enregistrement des charges d'exploitation pour le calcul de la marge nette.
- 📊 **Historique & Rapports :** Suivi chronologique des ventes réalisées et analyse du chiffre d'affaires.

---

## 🛠️ Installation locale

1. Cloner dans votre répertoire web :
   ```bash
   git clone https://github.com/bachirchaker/gestion_parfumerie.git
   ```
2. Importer `database.sql` dans MySQL / MariaDB (via phpMyAdmin ou CLI).
3. Configurer la connexion dans `config.php`.
4. Ouvrir `http://localhost/gestion_parfumerie/` dans votre navigateur.
